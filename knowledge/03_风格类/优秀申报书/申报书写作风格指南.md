# 申报书写作风格指南

> 风格类知识库定义「怎么写」。本文件为编者原创的写法规范；
> 真实优秀申报书范文由素材提供方脱敏后另存本目录，文件名一事一文。

## 一、语体总则

- 陈述句为主，少用感叹句、反问句。
- 第三人称「本项目」「该系统」，不用「我们」「咱们」。
- 动词开头写成果，不用「致力于」「努力实现」这类过程词。
  虚构示例：❌「本项目致力于提升检测效率」✅「检测效率由 62% 提升至 98%」。

## 二、数字写法（评审最看这条）

1. 每个数字带单位、带时间点或条件。
   ❌「精度很高」✅「2025 年 6 月自建测试集 12000 条上检测精度 99.2%」
2. 精确值不四舍五入：486.5 万元不写成「约 500 万」。
3. 对比写基线：有前值写前值，无前值写行业基线或标准值。
   ✅「较上一代方案能耗降低 37%」✅「优于 GB/T xxxx 限值 0.5 倍」
4. 关键数字必须有出处（专利号、检测报告编号、审计报告年份），
   出不了处的数字宁可不写。

## 三、技术描述的颗粒度

- 写到「能落地的技术点」为止：算法名、架构、参数、指标，不写教科书原理。
  ❌「运用了人工智能技术」✅「采用轻量化卷积网络 + 8bit 量化，
  模型体积 48MB，1GB 内存网关可运行」
- 技术指标写「可验证」的量：精度、延迟、功耗、体积、成本，
  不写「先进性」「领先水平」这类无主语定性。
- 每项技术与对应产品、对应知识产权挂钩，形成「技术—产品—专利」闭环。

## 四、成果写法

- 成果写可交付物：软件 N 套、样机 N 台、专利 N 项、标准 N 项、收入 N 万元。
- 专利写明状态与编号：「已授权 ZL2024 1 xxxxxxx.x」优于「拥有专利 1 项」。
- 软著写登记号，检测报告写出具机构与编号。

## 五、避坑清单

| 写法 | 问题 |
|---|---|
| 技术领先 / 国际先进 / 国内首创 | 无出处定性词，审查项「无据佐证」直接命中 |
| 大幅提升、显著降低、有效改善 | 无量词 = 没写，评审无法采信 |
| 一篇到底不分层 | 用「一、二、三」+ 小标题，评审按点给分 |
| 素材外发挥 | 没进素材的内容不写 —— 写了就是无出处，宁缺不编 |
| 大段政策原文 | 评审要看企业做了什么，不是政策复读 |

## 六、句式模板（可复用骨架，数据自行替换）

- 技术句式：「采用【技术方案】，实现【指标 + 数值 + 单位 + 条件】，
  支撑【产品 / 场景】。」
- 知识产权句式：「【专利名】（专利号 / 申请号，状态），解决【具体问题】，
  对应产品【产品名】的【技术指标】。」
- 成果句式：「形成【交付物 + 数量】；【指标】由【前值】提升至【现值】；
  已申请【专利类型 + 数量】。」
- 团队句式：「投入【人数】人，其中【职称/学历结构】；
  负责人【姓名】主持过【项目类型 + 数量】，获【奖项】。」

## 七、检查方法（成稿后自查）

1. 全文找「显著 / 大幅 / 先进 / 领先」—— 每处补数字或删除。
2. 全文数字逐个核对：有没有出处？和素材一致吗？单位对吗？
3. 每章标题下第一段能否 30 秒讲清「做了什么、做到什么程度」。
4. 找一段给不了解本项目的同事读，读不懂的地方就是写空的地方。
