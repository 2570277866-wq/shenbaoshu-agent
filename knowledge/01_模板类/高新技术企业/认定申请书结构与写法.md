# 高新技术企业认定申请书：结构与写法

> 本书用于生成初稿时的结构依据。官方口径以申报地认定机构当年通知为准。
> 全部示例数据为**虚构示例**，仅示范句式，不得当真实数据使用。

## 一、申请书主体结构（2016 年版）

1. 主要情况表 —— 企业概况 + 四大认定条件总览
2. 知识产权汇总表（IP01、IP02…）
3. 人力资源情况表 —— 职工总数、科技人员数（全年月平均数）
4. 企业研究开发活动情况表（RD01、RD02…，按单一活动填报，重要度排序）
5. 上年度高新技术产品（服务）情况表（PS01、PS02…）
6. 企业年度研究开发费用结构明细表（近三个会计年度，每年一张）

编号规则：IP = 知识产权，RD = 研发项目，PS = 高新技术产品（服务），后接两位序号。

## 二、核心评价指标（写初稿时逐条对齐）

| 条件 | 口径 |
|---|---|
| 科技人员占比 | 科技人员数 / 职工总数 ≥ 10% |
| 研发费用占比 | 近三年研发费用总额 / 同期销售收入总额，按销售额分档 5%/4%/3% |
| 境内研发费用 | 占研发费用总额比例 ≥ 60% |
| 高新产品（服务）收入 | 占同期总收入比例 ≥ 60% |
| 知识产权 | Ⅰ类（发明专利等）+ Ⅱ类（实用新型、软著等）；Ⅱ类仅限使用一次 |
| 科技人员定义 | 累计实际工作 183 天以上，含在职、兼职、临时聘用 |

## 三、各表写作要点

### 3.1 主要情况表

- 技术领域须与《国家重点支持的高新技术领域》最具体的三级领域对应，
  不是行业大类。示例句式：「所属技术领域：电子信息—软件—嵌入式软件」。
- 财务数据口径：销售收入 = 主营业务收入 + 其他业务收入；
  企业总收入 = 收入总额 − 不征税收入。各栏不得空缺，无内容填 0。

### 3.2 知识产权汇总表

- 按对主要产品（服务）的核心支持程度排序，不是按时间排序。
- 每项注明编号、类型（Ⅰ类/Ⅱ类）、取得方式（自主研发/受让等）、法律状态。
- 写法要点：写"该专利解决什么问题、支撑哪个产品（服务）"，不写专利摘要复读。

### 3.3 研究开发活动情况表（RD）

每项一个活动，写法：

- 研发活动名称：动词开头，写清对象。「基于 X 的 Y 技术研发」优于「Y 项目」。
- 起止时间、技术领域、技术来源（企业自主研发 / 产学研合作等）、经费。
- 核心技术及创新点：写与领域三级分类对应的**具体技术点**，
  忌「提升了性能、降低了成本」这类无主语表述。
  虚构示例：「创新点：将模型参数量由 7B 压缩至 0.5B，端侧推理延迟由 320ms
  降至 45ms，支撑工业网关无 GPU 部署。」

### 3.4 高新技术产品（服务）情况表（PS）

- 关键技术及主要技术指标：只写对产品指标和竞争力起主要作用的核心技术。
- 知识产权支持作用栏：逐一写明「哪件 IP 支持本产品哪项指标」，
  产品必须与企业自主知识产权关联。
  虚构示例：「PS01 智能边缘网关的核心推理引擎由 IP01（一种模型压缩方法
  发明专利）支撑，对应技术指标：单卡内存占用 ≤ 1GB。」

### 3.5 研发费用结构明细表

- 按人员人工、直接投入、折旧摊销、设计、装备调试、委托外部研发等科目归集，
  口径照财税〔2015〕119 号。
- 数字规范：带单位带年份，精确值不四舍五入；
  数据须与专项审计报告、年度财务报告、纳税申报表三方一致。

## 四、常见被扣分写法（初稿避坑）

- 技术领域选到一级大类 —— 评审无法定位，直接按领域不符处理
- RD/PS 写「显著提升」「大幅降低」不给量 —— 无据佐证，等于没写
- 知识产权与产品脱节 —— 有专利但没讲清支持关系，专利得分浪费
- 财务数据三处口径不一致 —— 人工审核重点，一处对不上牵连全局

## 五、初稿生成后的必查清单

- [ ] 六张表齐全，编号 IP/RD/PS 连续
- [ ] 每个 RD 的领域描述具体到三级领域
- [ ] 每个 PS 都挂至少一件自主知识产权并写明支持关系
- [ ] 所有数字挂出处（表格数据须与审计报告一致）
- [ ] 无「显著、大幅」类无主语定性词
