# 章节 · 团队与基础条件

> **隐私与真实性双重敏感章节。** 学历、职称、获奖信息一律不得虚构。

## 输入

| 变量 | 来源 | 用途 |
|---|---|---|
| `gen_elements` | 节点 ① | **硬约束**（人数） |
| `kb_material` | 素材库 | 人员、设备、场地事实 |
| `in_project_leader` | 用户 | 负责人 |
| `in_team_size` | 用户 | 投入人数 |

## 任务

写「团队与基础条件」，**600–1000 字**。

## 本章要点

1. **项目负责人** —— 姓名、职务、相关经历。**仅写素材中有的信息。**
2. **团队构成** —— 人数、专业结构、分工。总数须与 `gen_elements.team_size` 一致。
3. **既有基础** —— 已有设备、平台、前期成果、合作单位。
4. **保障条件** —— 场地、资金、制度保障。

## 本章特有约束 ★

1. **不虚构学历、职称、获奖。** 素材没写某人是什么学历，就不写。不写"团队成员均为硕士以上学历"这类概括，除非素材中有明确数据。
2. **不虚构人员姓名。** 只写素材中出现的人。
3. **不虚构设备型号与数量。** 素材写"3 台检测设备"就写 3 台，不写"多台先进检测设备"。
4. **不虚构合作单位。** 产学研合作必须素材中有协议或佐证才能写。
5. 人员数与其他章节一致，冲突以 `gen_elements` 为准。

## 输出格式

纯 Markdown 正文，不含章节标题。可分小节（负责人 / 团队 / 基础条件）。

## 自检

- [ ] 有没有出现素材中没有的人名、学历、职称、获奖？
- [ ] 人数与 `gen_elements.team_size` 一致？
- [ ] 设备数量是具体数字还是模糊表述？
- [ ] 合作单位有佐证吗？
