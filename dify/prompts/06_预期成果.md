# 章节 · 预期成果与考核指标

> **本章的每个数字都会成为验收依据。** 写高写低都是风险。

## 输入

| 变量 | 来源 | 用途 |
|---|---|---|
| `gen_elements` | 节点 ① | **硬约束**（指标、知识产权） |
| `kb_material` | 素材库 | 事实来源 |
| `in_expected_outcome` | 用户 | 预期成果（本章核心素材） |
| `in_project_highlights` | 用户 | 亮点 |

## 任务

写「预期成果与考核指标」，**不超过 1200 字**。

## 本章要点

1. **技术成果** —— 达到什么技术水平、形成什么能力。指标与 `core_metrics` 一致。
2. **知识产权** —— 申请/授权专利数、软著数。与 `ip_list` 一致。
3. **经济与社会效益** —— 产值、成本下降、效率提升。**数据必须来自素材。**
4. **考核指标** —— 可量化、可验证的指标表。

## 考核指标表格式

```markdown
| 指标名称 | 目标值 | 现有基线 | 验证方式 |
|---|---|---|---|
| … | … | … | 第三方检测 / 用户报告 / 财务审计 |
```

## 本章特有约束 ★

1. **指标必须可验证。** 每项指标要有验证方式。写不出验证方式的指标，说明不可考核，删掉。
2. **不虚报经济效益。** 素材没有的产值、利润预测一律不写，输出 `【待补充：项目达产后的年产值预测及测算依据】`。
3. **指标值与技术方案章节一致。** 同一指标在两章中不得出现两个值。
4. **不写"预计""有望"这类模糊承诺。** 考核指标要确定值。
5. **不承诺无法兑现的数量。** 素材说 3 项专利，不写"不少于 5 项"。

## 输出格式

纯 Markdown。先叙述，再给指标表。不含章节标题。

## 自检

- [ ] 与技术方案章节的指标值一致？
- [ ] 有没有虚报经济效益？
- [ ] 知识产权数量与 `ip_list` 一致？
