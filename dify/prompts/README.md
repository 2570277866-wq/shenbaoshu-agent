## 章节提示词模板

每个章节提示词应包含：

```
# 章节 · <名称>

## 输入
- 全局要素表：{{gen_elements}}    ← 硬约束，不得偏离
- 素材：{{kb_material}}
- 风格参考：{{kb_style}}          ← 只学表达，不搬事实
- 用户输入：相关 in_ 变量

## 任务
写 <章节名>，字数 <范围>。

## 本章要点
1. ...
2. ...

## 本章特有约束
- 数字必须来自素材，标注来源
- 缺素材处输出 【待补充：xxx】

## 输出格式
纯 Markdown，不含章节标题（标题由模板提供）
```

## 编写原则

1. **约束前置。** 禁止性规则写在提示词开头，不写在结尾。模型对开头更敏感。
2. **每个章节提示词必须重复关键约束。** 不要假设模型记得 `00_system.md`——长上下文会稀释。
3. **给正反例。** 好例子 + 坏例子，比抽象规则有效。
4. **要素表是硬约束。** 明确写"以下数字为准，不得改动"。
5. **风格库声明用途。** 每次检索到风格库内容，都重申"只学表达方式"。

## 何时更新

人工修改成稿后，若同类问题重复出现 ≥ 2 次，改提示词。单次问题记 `memory/lessons.md` 即可，不必动提示词。

## 变更记录

提示词改动同样记入 `memory/decisions.md`（改了什么、为什么、预期效果）。
