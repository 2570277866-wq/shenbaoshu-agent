# 章节 · 经费预算

> **金额是最敏感的字段。** 本章只做组织与呈现，不做任何测算。

## 输入

| 变量 | 来源 | 用途 |
|---|---|---|
| `gen_elements` | 节点 ① | **硬约束**（总额、明细） |
| `kb_material_finance` | 素材-财务数据 | 金额来源 |
| `in_budget_range` | 用户 | 预算规模 |

## 任务

写「经费预算」，**不超过 800 字**，并输出预算明细表。

## 本章要点

1. **预算总额** —— 与 `gen_elements.total_budget` 一致。
2. **分项明细** —— 各科目金额、占比、用途说明。与 `budget_breakdown` 一致。
3. **测算依据** —— 各项金额怎么来的。**依据必须来自素材。** 没有依据的写 `【待补充：××费用的测算依据】`。
4. **资金来源** —— 自筹与申请资助的比例。

## 预算表格式

```markdown
| 科目 | 金额（万元） | 占比 | 说明 |
|---|---|---|---|
| 设备费 | … | … | … |
| **合计** | **…** | 100% | |
```

## 本章特有约束 ★

1. **不做任何推算。** 不得由总额倒推分项，不得由分项凑总额。分项之和与总额不符时，**原样呈现并标注矛盾**，交人工处理。
2. **占比由金额计算得出**（这是唯一允许的计算），保留一位小数。
3. **不编造测算依据。** 不写"参照行业惯例""按市场均价估算"。
4. **金额格式统一**：`320.00 万元`，不混用"元""万元""万"。
5. **资助比例不得臆断。** 素材没有就写 `【待补充：申请资助金额及占比】`。

## 输出格式

纯 Markdown。先简述总额与来源，再给明细表。不含章节标题。

## 自检

- [ ] 分项之和等于总额？（不等则已标注）
- [ ] 金额与 `budget_breakdown` 逐项一致？
- [ ] 有没有自己算出来的金额？
- [ ] 单位统一为"万元"？
- [ ] 占比计算是否正确？
