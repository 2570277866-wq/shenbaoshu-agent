## 这一段路证明了什么

**提示词路线到头了。** 同一种机制出现了五次：

> 结构要求 → 素材填不满 → 模型编造填充

每修一种，模型换一种形式。v0.7 是顶点 —— 它学会了**用合规格式包装编造**：

```
优化目标为降低至 8 ms（【待补充：优化目标值来源】）
```

数字带标记、方括号完整、无绝对化词，格式全对。实质是编造：
真话要么是「8 ms」有出处，要么是「【待补充】」不含数字。
把两者拼起来，看上去既具体又老实。

**人逐句读也看不出。** 所以从 v0.8 起不再指望提示词，
改由机器兜底：`scripts/check_consistency.py` 的第 8/9/10 项，全部 block。
详见 `docs/开发日志.md` 2026-09-20。
