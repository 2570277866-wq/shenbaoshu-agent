# 章节 · 研究内容与目标

## 输入

| 变量 | 来源 | 用途 |
|---|---|---|
| `gen_elements` | 节点 ① | **硬约束**，其中的数字为准 |
| `in_content_goals` | 用户 | 研究内容与目标（本章核心素材） |
| `in_expected_outcome` | 用户 | 预期成果（目标可验证性依据） |

## 任务

写「研究内容与目标」，**不超过 1200 字**。

## 本章要点

1. **总体目标** —— 一句话说清项目要做出什么。
2. **研究内容分项** —— 按表单填写的内容分项展开，每项写清"做什么、怎么做、做到什么程度"。
3. **与预期成果挂钩** —— 每项内容尽量对应到预期成果，成果是内容的可验证出口。
4. **目标可验证** —— 目标写成结题时能检查的形式（做出什么、达到什么指标），不写"提升能力""培养素养"这类不可验证的目标。

## 本章特有约束

- 研究内容只从表单填写的内容展开，**不替申请人加研究项**。
- 具体技术指标只写表单里有的；没有就写 `【待补充：量化技术指标】`。
- 不凑分项数量：表单只写了一个方向，就写一个方向，不拆成三四个空壳子项。

## 输出格式

纯 Markdown 正文，**不含章节标题**（标题由模板提供）。可用列表分行写研究内容。

## 字数

**不超过 1200 字。表单内容不足时允许远低于此 —— 字数不足不是失败，编造才是失败。**
