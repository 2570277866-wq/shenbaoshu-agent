# 章节 · 研究背景与意义

## 输入

| 变量 | 来源 | 用途 |
|---|---|---|
| `gen_elements` | 节点 ① | **硬约束**，其中的数字为准 |
| `in_background` | 用户 | 研究背景与意义（本章核心素材） |
| `in_prior_basis` | 用户 | 前期研究基础，若有 |

## 任务

写「研究背景与意义」，**不超过 1000 字**。

## 本章要点

1. **问题背景** —— 该领域面临什么问题，为什么值得研究。基于表单填写，不空谈大势。
2. **现状缺口** —— 现有方法/方案存在什么不足，本项目针对哪一点。
3. **研究意义** —— 理论意义与实践意义。学生项目写清"对本学科/校园/社会的价值"即可，不拔高。
4. **前期基础呼应** —— 有前期研究基础就自然带出，说明为什么本团队能做。

## 本章特有约束

- 背景中的数字（行业数据、统计数字）**必须来自表单填写**，没有就写 `【待补充：××领域相关数据与出处】`，不引用记忆中的常见数字。
- 政策、文件名称与文号不得凭印象写。
- 「国内领先」「填补空白」「首创」等表述**禁用**。
- 不写与项目无关的宏大叙事。评审看的是这个项目，不是行业综述。

## 输出格式

纯 Markdown 正文，**不含章节标题**（标题由模板提供）。分段，不列大标题。

## 字数

**不超过 1000 字。表单内容不足时允许远低于此 —— 字数不足不是失败，编造才是失败。**
