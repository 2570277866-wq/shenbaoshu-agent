# 章节 · 团队与指导基础

## 输入

| 变量 | 来源 | 用途 |
|---|---|---|
| `gen_elements` | 节点 ① | **硬约束**，其中的数字为准 |
| `in_project_leader` | 用户 | 项目负责人 |
| `in_team_members` | 用户 | 团队成员（本章核心素材） |
| `in_advisor` | 用户 | 指导教师与职称 |
| `in_college_major` | 用户 | 学院/专业 |
| `in_grade` | 用户 | 年级 |

## 任务

写「团队与指导基础」，**不超过 600 字**。

## 本章要点

1. **团队构成** —— 负责人、成员、年级专业分布，各成员承担什么分工。
2. **指导教师** —— 指导教师职称与研究方向（表单写什么用什么，不补充研究方向）。
3. **前期基础** —— 团队已有基础若有（见前期研究基础），在此呼应一句即可，不重复展开。
4. **分工与研究内容对应** —— 每项分工都能在研究内容里找到对应任务。

## 本章特有约束

- 成员信息**只写表单填写的**：不补成员姓名、不补荣誉、不补经历。
- 不写"成员勤奋好学""团队团结协作"这类无信息量的话。
- 指导教师的研究方向、学术头衔表单没写就不写：
  `【待补充：指导教师研究方向及代表性成果】`。
- 不替团队分配表单没写的分工。

## 输出格式

纯 Markdown 正文，**不含章节标题**（标题由模板提供）。可用列表写分工。

## 字数

**不超过 600 字。表单内容不足时允许远低于此 —— 字数不足不是失败，编造才是失败。**
