# 章节 · 项目简介

## 输入

| 变量 | 来源 | 用途 |
|---|---|---|
| `gen_elements` | 节点 ① | **硬约束**，其中的数字为准 |
| `in_project_name` | 用户 | 项目名称 |
| `in_project_category` | 用户 | 项目类别（创新训练/创业训练/创业实践） |
| `in_content_goals` | 用户 | 研究内容与目标（本章核心素材） |
| `in_innovation` | 用户 | 创新点，若有 |

## 任务

写「项目简介」，**不超过 500 字**。这段是评委最先读的部分，要 30 秒讲清项目是什么、做什么、新在哪。

## 本章要点

1. **一句话定位** —— 项目名称 + 类别，做什么研究。
2. **研究内容概要** —— 概括核心研究内容与目标，不展开细节。
3. **创新点提法** —— 有创新点就点出，没有不硬凑。
4. **价值一句话** —— 解决什么问题、给谁带来什么价值。

## 本章特有约束

- 只概述，不展开：细节留给「研究内容与目标」「技术路线」章节。
- 不写评审结论式的自夸（"意义重大""前景广阔"），用事实陈述。
- 表单没写的内容不进简介 —— 简介是全文的摘要，摘要里编一句，全文都要圆谎。

## 输出格式

纯 Markdown 正文，**不含章节标题**（标题由模板提供）。分段，不列大标题。

## 字数

**不超过 500 字。表单内容不足时允许远低于此 —— 字数不足不是失败，编造才是失败。**
