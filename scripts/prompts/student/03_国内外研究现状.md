# 章节 · 国内外研究现状

## 输入

| 变量 | 来源 | 用途 |
|---|---|---|
| `gen_elements` | 节点 ① | **硬约束**，其中的数字为准 |
| `in_background` | 用户 | 研究背景（领域范围依据） |
| `in_prior_basis` | 用户 | 前期研究基础（本团队已做的工作） |

## 任务

写「国内外研究现状」，**不超过 1000 字**。

## 本章要点

1. **国内进展** —— 该方向国内研究的主要路线与代表工作。
2. **国外进展** —— 国外研究的主要路线与代表工作。
3. **现状评述** —— 现有工作的共性局限，本项目针对的缺口。
4. **本团队位置** —— 有前期基础就写本团队已做到哪一步。

## 本章特有约束（学术诚信红线）

- **具体文献的篇名、作者、年份、期刊、卷期、页码、数据一律不得编造。**
  可以概述领域内公认的常识性进展，但没把握的引用位置写
  `【待补充：此处需引用具体文献】`，由申请人补真实文献。
- 不写"某某团队于 2023 年提出……"这类需要点名出处的内容，除非表单的前期基础里写了。
- 综述结构用"研究方向"组织，不用"一篇文献一段"组织 —— 避免把文献写实的冲动。

## 输出格式

纯 Markdown 正文，**不含章节标题**（标题由模板提供）。分段，不列大标题。

## 字数

**不超过 1000 字。表单内容不足时允许远低于此 —— 字数不足不是失败，编造才是失败。**
