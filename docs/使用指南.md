# 使用指南（企业操作版）

> 面向企业操作人员。无需技术背景，按步骤操作即可。

---

## ⚠️ 先读这一段

本系统生成的是**申报书初稿**，不是可直接提交的成品。

- 系统会写：结构、行文、把您提供的素材组织成申报书语言
- 系统不会：核实数据真假、判断申报策略、替代专业审核

**提交前必须由人逐项核对。** 特别是所有数字、资质、专利号、财务数据。
系统对没有素材的内容会标注 `【待补充：xxx】`，这些位置必须由您补全。

**未经人工审核的稿件，请勿对外提交。** 申报材料造假后果由申报单位承担。

---

## 一、准备工作

开始前需要准备好这些材料。

### 1.1 必填信息（10 项）

| 项目 | 说明 | 示例 |
|---|---|---|
| 申报类型 | 下拉选择 | 科技型中小企业 |
| 项目名称 | 完整名称 | 面向工业质检的机器视觉缺陷检测系统 |
| 技术方向 | 所属技术领域 | 人工智能 / 机器视觉 |
| 项目负责人 | 姓名 | 张三 |
| 投入人数 | 数字 | 8 |
| 预算规模 | 金额区间 | 500 万元 |
| 预期成果 | 多行文本，写清要达成什么 | 完成 3 项发明专利、实现产线部署… |
| 项目亮点 | 多行文本，写清比别人强在哪 | 检测精度达 99.2%，较行业平均提升… |
| 特殊要求 | 选填。有申报指南特殊要求的填这里 | 需突出产学研合作 |
| 参考文件 | 选填。上传申报指南、企业已有材料 | PDF / Word / 图片 |

### 1.2 素材准备建议

**预期成果和项目亮点的写法直接决定成稿质量。** 建议：

- 写具体，不写空话。❌"技术领先" ✅"检测精度 99.2%，误检率低于 0.5%"
- 带数字，带对比。有基线数据的一定写上
- 有专利、软著、检测报告的，把编号一并写上

## 二、操作步骤

### 步骤 1：打开系统

浏览器访问系统地址（由技术人员提供），进入申报书生成应用。

### 步骤 2：填写表单

按 1.1 表格逐项填写。带 **\*** 的为必填项。

- 下拉框：选择申报类型
- 数字框：只填数字，不带单位
- 多行文本：可以分段，回车换行

### 步骤 3：上传参考文件（可选，但强烈建议）

有申报指南的**务必上传**。系统会解析指南中的评审要点和格式要求，生成内容会更贴合。

支持格式：PDF、Word、TXT、图片。

### 步骤 4：点击生成

点击"生成"按钮。系统开始工作。

**等待时间：** 约 20–40 分钟（取决于项目复杂度与硬件配置）。
**期间请勿关闭页面。** 可以最小化窗口做别的事。

生成过程：
1. 解析上传文件
2. 检索知识库素材
3. 逐章节生成
4. 一致性检查
5. 排版输出

### 步骤 5：下载初稿

生成完成后，点击下载按钮获取文件：

- `.docx` —— 可直接用 Word 打开编辑
- `.md` —— 纯文本版本，备用

文件名会带 `_DRAFT` 后缀，提醒这是初稿。

### 步骤 6：人工审核 ★ 必做

**这一步不能省。** 按下面的清单逐项过。

## 三、审核清单（提交前逐项核对）

### 3.1 数字类 ★ 最高优先级

| 检查项 | 怎么查 |
|---|---|
| 财务数据 | 每个金额与财务报表核对 |
| 人员数量 | 与花名册核对 |
| 时间周期 | 与项目计划核对 |
| 技术指标 | 与检测报告、测试记录核对 |
| 专利/软著号 | 到官方系统逐个查验 |

**发现对不上的数字，一律以您的原始材料为准，直接改。** 系统可能理解偏差。

### 3.2 标注类

搜索文档中的 `【待补充】`，逐个补全。这些是系统明确表示"没素材、不敢写"的位置。

**不要直接删掉标注。** 每个标注都对应申报书的一个必填内容，删了就是空缺。

### 3.3 表述类

| 检查项 | 说明 |
|---|---|
| 绝对化表述 | "国内领先""国际先进""填补空白" —— 无佐证的删掉或改弱 |
| 与事实不符 | 系统不会核实真假，写得好听不等于真 |
| 申报策略 | 突出的重点是否符合本次申报导向 |
| 语体一致 | 全文风格是否统一 |

### 3.4 格式类

- 章节顺序是否符合申报系统要求
- 表格是否完整未错位
- 是否有遗留的 `{{ }}` 占位符

## 四、常见问题

**Q：生成的内容有事实错误怎么办？**
A：直接改。系统基于您提供的素材生成，素材不全会导致理解偏差。改完后可以反馈给我们，用于改进系统。

**Q：为什么有些地方写着【待补充】？**
A：这些内容知识库里没有素材，系统按规则拒绝编造。需要您提供材料后重新生成，或手工补上。

**Q：生成的文档找不到下载按钮？**
A：生成耗时较长，请等待页面提示完成。若超过 60 分钟未完成，联系技术人员。

**Q：可以生成多个申报类型吗？**
A：可以，重新选择申报类型再生成一次。不同类型的结果请分别保存，不要混用。

**Q：内容不满意，能重新生成吗？**
A：可以。补充更详细的"预期成果""项目亮点"后重新生成，效果会明显改善。**输入越具体，输出越可用。**

**Q：数据安全吗？**
A：系统本地部署，您的材料不会上传到任何外部服务器。脱敏要求见下。

**Q：可以上传含个人隐私的材料吗？**
A：上传前请自行脱敏：身份证号、银行账号、未公开的客户名称等建议移除。系统不做自动脱敏。

**Q：生成的内容能直接用吗？**
A：不能直接提交，但可以作为很好的起点。经验上人工修改量在 30% 以内即可定稿。

## 六、给操作人员的三条建议

1. **输入决定输出。** 花 30 分钟把"预期成果"和"项目亮点"写扎实，比生成后改 3 小时划算。
2. **把系统当实习生。** 它能把素材组织成申报书的样子，但不懂您的业务，也不会替您担责。
3. **每次修改都值得记录。** 您的大幅改动是我们改进系统的依据，欢迎反馈。
