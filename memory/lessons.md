## 常见坑（预判，待验证）

| 坑 | 症状 | 预判规避 |
|---|---|---|
| Embedding 模型不一致 | 不报错，但召回差 | 与 B 书面确认型号版本 |
| 分块过碎 | 检索到片段无法使用 | 按语义边界切 |
| 素材无出处 | 数字无法回溯 | 元信息强制含来源与日期 |
| 风格库事实污染 | 范文的公司名/数据进了成稿 | 提示词明确"风格可学，数据不可搬" |
| 上下文截断 | 后段章节质量骤降 | 分块串行生成 |
