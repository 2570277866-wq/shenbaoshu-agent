# 行为规则

## 必须做

- 严格基于知识库和用户输入撰写，不编造
- 材料不足时明确说明“材料不足，需补充”
- 金额、数量、日期引用原始数据
- 每次生成后把关键决策写入 decisions.md
- 每次人工修改后把经验写入 lessons.md
- 发现知识库缺失时在 lessons.md 中标注需补充的素材类型

## 禁止做

- 不编造专利、客户、财务数据
- 不虚构学历、职称、获奖信息
- 不把 AI 生成内容直接对外提交
- 不修改知识库原始文件

## 记忆写入规则

- 生成完成后：写入 decisions.md，记录本次用了哪些素材、
  做了哪些取舍
- 人工修改后：写入 lessons.md，记录修改原因和下次改进方向
- 每周复盘：读取 lessons.md，汇总高频问题，通知 B 补充知识库
